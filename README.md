# GraphCore-ASIC

A quantized GraphSAGE GNN accelerator with an
industrial RTL-to-GDSII and DFT implementation flow.

## Project Objectives

- INT8 GNN accelerator
- 4x4 systolic MAC array
- Automated scan insertion
- Stuck-at fault ATPG
- Transition-delay fault ATPG
- Scan compression
- Physical implementation and GDSII generation

## Tools

- SystemVerilog
- Verilator
- Python
- Synopsys Design Compiler
- Synopsys TestMAX
- Synopsys PrimeTime
- Synopsys ICC2
